# AI Video Generator

## Overview
This n8n workflow generates AI-powered videos from text prompts and user-provided images through Telegram.

Users simply send a prompt and one or more images to a Telegram bot, and the workflow automatically generates a video using an AI video generation model before sending the final video back to Telegram.

## Features

- Generate videos from text prompts
- Accept images directly from Telegram
- AI-powered video generation
- Automatic video delivery
- Fully automated n8n workflow

## Technologies

- n8n
- Telegram Bot API
- AI Video Generation API
- HTTP Requests
- Workflow Automation

## Workflow File

Import the JSON workflow into n8n, configure your credentials and API keys, then execute the workflow.
