# AI Hospital Booking System

## Overview

This n8n workflow automates the complete hospital appointment booking process.

Patients can view available departments, doctors, appointment slots, book appointments, complete online payment, receive a confirmation email, and submit doctor ratings after their visit.

## Features

- Browse hospital departments
- View available doctors
- Check available appointment slots
- Book appointments automatically
- Online payment integration
- Email confirmation with appointment details
- Doctor rating and feedback system
- Fully automated workflow

## Technologies

- n8n
- AI Agents
- Email Automation
- Payment Gateway
- Google Sheets / Database
- APIs
- Workflow Automation

## Future Enhancements
