# 🤖 AI News → LinkedIn Automation

An n8n workflow that finds the latest AI news from the last 24 hours, uses AI to turn the most relevant story into a LinkedIn post, fact-checks it, and sends it to Telegram for approval before publishing.

**Find → Create → Review → Publish**

![Workflow](workflow.png)

### Tech Stack
- n8n
- LLM / AI
- Telegram Bot
- LinkedIn API
- News / RSS Sources

### Workflow
**Daily at 5:00 AM → AI News → AI Analysis → Post Generation → Fact Check → Telegram Approval → LinkedIn**

The goal is simple: **use small automations to save time and make content creation easier.**
