# AI Certificate Generator

## Overview
This n8n workflow automatically generates personalized certificates for trainees after course completion.

The user only enters each trainee's final grade, and the workflow automatically:
- Generates a personalized certificate.
- Creates a PDF version.
- Sends the certificate to the trainee via email.
- Eliminates manual certificate creation.

## Technologies
- n8n
- Google Docs
- Google Drive
- Gmail
- AI Automation

## Features
- Automatic certificate generation
- Personalized trainee information
- PDF export
- Email delivery
- Fast and scalable workflow

## Workflow File
Import the `workflow.json` file into n8n and configure your credentials before running.
